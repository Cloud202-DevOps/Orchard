## Security Boundaries

```
┌─────────────────────────────────────────────────────────────────────┐
│                    Internet (Untrusted)                               │
└────────────────────────────┬────────────────────────────────────────┘
                             │ HTTPS (recommended)
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│                    IIS (Reverse Proxy / Host)                         │
│  - SSL termination                                                  │
│  - Request filtering                                                │
│  - Static file serving                                              │
└────────────────────────────┬────────────────────────────────────────┘
                             │
                             ▼
┌─────────────────────────────────────────────────────────────────────┐
│              Orchard Application (Trust Boundary)                     │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │ Authentication Layer (Forms Auth)                            │    │
│  │  - Cookie validation                                        │    │

│  └─────────────────────────────────────────────────────────────┘    │
│  ┌─────────────────────────────────────────────────────────────┐    │
│  │ Authorization Layer (Permission checks)                      │    │
│  │  - Role-based access                                        │    │
│  │  - Content-level permissions                                │    │
│  └─────────────────────────────────────────────────────────────┘    │

└─────────────────────────────────────────────────────────────────────┘
```
